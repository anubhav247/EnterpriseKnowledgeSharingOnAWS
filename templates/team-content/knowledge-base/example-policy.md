# Example Policy

Replace this file with your team's own documents. Each markdown file needs the
front matter block above: title, category, owner and tags. A document needs at
least 200 characters of body text, and every title must be unique.

## Writing tips

Write one topic per document and use clear section headings: the search returns
sections, so a good heading helps the right passage come first. Put the words
people will ask with into the text, and keep tables simple.
